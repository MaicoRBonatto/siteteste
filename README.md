# Santa Luzia do Rio Claro: memória da comunidade

Site estático de exemplo (HTML puro, sem instalação).

- `index.html`: a página
- `fotos/`: fotos da comunidade (nomes conforme o `index.html`)

Para trocar textos, edite o `index.html`. Para trocar as fotos, coloque os arquivos em `fotos/` com os nomes esperados.
